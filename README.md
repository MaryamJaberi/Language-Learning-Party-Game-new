# دور: زبان — بازی دورهمی یادگیری زبان

یک گوشی، چند نفر، یک زبان تازه. بازیکن‌ها دور هم می‌نشینند، گوشی دست‌به‌دست می‌چرخد و هر کس باید واژه یا جملهٔ روی صفحه را به زبانِ هدف بگوید یا حدس بزند. اول بازی است، بعد درس.

نسخهٔ زنده: https://maryamjaberi.github.io/Language-Learning-Party-Game/

## چه دارد

- بازی گروهی ۴، ۶ یا ۸ نفره با یک گوشی، و حالت تک‌نفره و دوئل
- 51 زبان در فهرست زبان‌ها، با سطح‌بندی CEFR (از A1 تا C1)
- کارت چالش و شمارندهٔ زنجیرهٔ پاسخ درست (فقط نمایشی، بدون امتیاز اضافه)
- مرور واژه‌های اشتباه با جعبهٔ لایتنر و موتور سختیِ تطبیقی
- کار بدون اینترنت (PWA) و بستهٔ اندروید

## اجرا

```bash
npm install
npm run dev      # اجرای محلی
npm run build    # ساخت نسخهٔ نهایی
```

مربی هوش مصنوعی و جدول امتیاز به سرور و کلید نیاز دارند؛ نسخهٔ گیت‌هاب بدون آن‌ها هم بازی می‌شود.

## تست‌ها

```bash
npm test             # ۳۰ فایل تست واحد و مسیر کاربر (vitest)
npm run test:rules   # قاعده‌های پایگاه‌داده؛ شبیه‌ساز Firestore باید روشن باشد
```

وضعیت در آخرین اجرا (۱۸ نوامبر ۲۰۲۶): ۲۰۷ تست قبول، ۲۵ تست رد. تست‌های ردشده در این فایل‌ها هستند و باید یکی‌یکی بررسی شوند که تست کهنه شده یا بازی باگ دارد:

| فایل | رد |
|---|---|
| dorAdaptiveEngine | ۶ |
| comprehensiveMasteryAndMatchmaking | ۴ |
| duelAndDiverseScenarios | ۴ |
| userFlows | ۴ |
| setupScreenFull | ۳ |
| challengeAndComboSystem | ۲ |
| comprehensiveUsabilityAndQualityAudit | ۲ |

تست‌های دستی که هنوز کسی انجام نداده: بازبینی ترجمهٔ واژه‌ها به دست یک گویشور بومی برای هر زبان، و یک دور کامل با چهار نفر واقعی.
