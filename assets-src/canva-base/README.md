# برگه‌های پایهٔ Canva

همهٔ تصویرهای کارت‌ها و دیکشنری از این برگه‌ها چیده می‌شوند. هر کارت فایل تصویر جداگانه ندارد.

## برگه‌ها

۴۸ برگه در Canva ساخته شده‌اند و در طرح «Plain image sheet» (`DAHbdxZmOzo`)، صفحه‌های ۳۵ تا ۸۲، هستند. شناسهٔ media هر برگه در `assets.json` آمده است.

| نوع | تعداد | توضیح |
|---|---|---|
| شخصیت (`char_*`) | ۲۱ | هر کدام ۸ حالت در شبکهٔ ۴×۲: آرام، دست تکان دادن، نگران/دلداری، مریض/سرفه، اشاره، تلفن، غمگین، خنده |
| مکان (`place_*`) | ۱۵ | پس‌زمینهٔ خالی، ۳:۲ |
| وسیله (`props_*`) | ۷ | ترتیبشان در `prop_groups.json` است |
| حیوان (`animals_*`) | ۲ | |
| شغل (`jobs_*`) | ۳ | هر برگه ۶ شغل |

## بریدن برگه‌ها

برگه‌ها را با اندازهٔ کامل و به صورت PNG خروجی بگیر و در پوشهٔ `sheets/` بگذار. بعد اجرا کن:

```
python3 build_lib.py ../../public/data/art
```

- هر تکه با پس‌زمینهٔ شفاف و به صورت WebP ذخیره می‌شود. کل کتابخانه حدود ۳٫۷ مگابایت است.
- فهرست تکه‌ها در `art.json` ساخته می‌شود.
- برای حالت‌های اشاره و دلداری، سمتی که دست به آن دراز شده (`reach`) ثبت می‌شود تا اپ دست را رو به طرف مقابل بچرخاند.

## چیدن صحنه

- `src/visual/ArtScene.tsx` صحنهٔ هر کارت را در اپ می‌چیند: مکان، شخصیت‌ها با حالت مناسب، وسیله‌ها و نشانه‌ها.
- صحنهٔ هر کارت از `public/data/scenes` می‌آید و همان موقعیتی است که برای کارت نوشته شده است.
- `src/visual/ArtThumb.tsx` تصویر واژه‌های دیکشنری را می‌سازد.
- اگر تکه‌ای نباشد، طرح کدی جایش را می‌گیرد.
