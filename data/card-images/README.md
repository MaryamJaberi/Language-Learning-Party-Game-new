# تصویر کارت‌ها

هر کارت یک «مفهوم» دارد (`conceptId`) که در همهٔ زبان‌ها یکی است. پس هر تصویر برای همهٔ زبان‌های آن کارت کار می‌کند.

| فایل | چه چیزی در آن است |
| --- | --- |
| `data/card-images/plan.json` | نقشهٔ کامل: برای هر مفهوم، به ترتیب سطح (Pre-A1 تا C2)، شناسهٔ کارت‌ها، سطح، موضوع، شخصیت فامیل، پرامپت تصویر، وضعیت (`todo` / `done`) و شناسهٔ تصویر در Canva |
| `public/data/card-images/<conceptId>.webp` | خود تصویر، ۶۰۰ پیکسل عرض |
| `public/data/card-images/manifest.json` | فقط تصویرهای آماده؛ بازی از این فایل می‌فهمد کدام کارت تصویر دارد |
| `components/CardImage.tsx` | نمایش تصویر روی کارت (بازی گروهی و تک‌نفره)؛ اگر تصویر نباشد چیزی نشان نمی‌دهد |
| `scripts/card-images/build_plan.py` | ساختن یا به‌روزکردن نقشه از دیتابیس کارت‌ها (وضعیت تصویرهای ساخته‌شده حفظ می‌شود) |
| `scripts/card-images/ingest.py` و `ingest_sheet.py` | دانلود تصویرهای خروجی Canva، تبدیل به WebP و به‌روزکردن نقشه و manifest |

شخصیت‌ها از سند «فامیل بزرگ دور» آمده‌اند. تصویرها در Canva ساخته می‌شوند.
